# Generative AI Research

This repository contains research materials for the project
"Using Generative AI Tools - Boon or Bane."

## Repository Structure

- 01_Literature_Review: books and journal articles
- 02_Quantitative_Analysis: survey data, scripts and results
- 03_Qualitative_Analysis: interview transcripts
- 04_Drafts_and_Reports: proposals, reports and submissions
- 05_Additional_Materials: supporting diagrams and project materials

## Collaboration

Please use clear file names and meaningful commit messages.
Pull the latest version before making changes and push changes after committing.
